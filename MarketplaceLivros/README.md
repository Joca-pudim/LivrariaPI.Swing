# Marketplace de Livros

Sistema de loja online com marketplace (Java + Swing + SQL Server). Lojas cadastram seus livros;
clientes pesquisam, montam o carrinho, finalizam a compra e "pagam".

## Como executar
Utilize os drivers JBDC quando for rodar esse codigo, certifique que ele esta na livraria
